# clorb

Clone orbs smartly by git branches

Example use:

```text
➜ clorb my-cool-branch
```

## Other commands

### Purge all Orbs created with clorb

```text
➜ clorb _purge
```

### List all Orbs created with clorb

```text
➜ clorb _list
```

## Dev

```sh
just install
just dev
```

and then run, in another terminal:

```sh
./out/clorb --help
```
